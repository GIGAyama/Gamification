# 📮 学習ログ送信ページ（study-log-sender）

GIGA山 学習アプリ群（Qalc / 漢字タウン / けいさんカード / さんすうブロック / 100マス計算）が
端末の `localStorage`（キー: `study.records.v1`）に保存する **study.v1 共通学習ログ** を、
まなびクエスト（GAS Webアプリ）へ送信するための静的ページです。

「学習ログ共通スキーマ仕様書 study.v1」でいう **送信ページ** の実装にあたります。

> **📌 新規導入は [`../manabi-portal/`](../manabi-portal/) を推奨します。**
> ポータルは、まなびクエスト本体を iframe で表示しながら同じ画面から送信できる上位版です
> （送信先URL・送信キー・出席番号の設定は同じ localStorage キーを共有するので併用できます）。
> このページは「送信だけしたい」場合の単機能版として残しています。

- 学習アプリは保存のみを行い、外部送信はこのページだけが行います（仕様 §0-1）
- 児童を識別する情報（出席番号）はこのページが付与します。アプリ層は匿名のままです（仕様 §0-2）
- 送信済み（受理・重複・形式エラー）のレコードは端末から削除します（仕様 §1.3）

## 配置場所

**学習アプリと同一オリジン**に置く必要があります（localStorage を共有するため）。

```
https://gigayama.github.io/study-log-sender/index.html
```

gigayama.github.io リポジトリに `study-log-sender/` フォルダとして `index.html` をコピーしてください。

## セットアップ手順

1. **まなびクエスト側（受信側）の準備**
   1. `unified/` の最新スクリプトを反映し、メニュー「① 初期セットアップ」を再実行（「学習ログ」シートが作成されます）
   2. 「初期設定」シートの **`学習ログ送信キー`** に合言葉（例: `sakura-3nen`）を設定し、メニューの「🔄 設定キャッシュをクリア」を実行
   3. Apps Script で **受信用のデプロイ**を作成:
      「デプロイ → 新しいデプロイ → ウェブアプリ」で
      - 実行ユーザー: **自分**
      - アクセスできるユーザー: **全員**（匿名アクセス。送信ページの fetch は Google ログイン情報を送れないため）
      - 発行された URL（`…/exec`）が送信先になります
      - ※ 児童が使う本体アプリのデプロイ（アクセス: 組織内）とは**別のデプロイ**として共存できます。
        受信用 URL を開いても、児童マスタ登録者以外はアプリを利用できません
2. **送信ページの設定**
   - 次の形式の URL を一度開くと設定が端末に保存されます（以後はパラメータ不要）:
     ```
     https://gigayama.github.io/study-log-sender/?endpoint=<受信用デプロイのURL>&key=<学習ログ送信キー>
     ```
   - この URL を Classroom などで児童に配付してください
   - ページ内の「⚙️ せってい（先生用）」から手動設定・接続テストもできます
3. **児童の操作**
   1. 送信ページを開き、自分の**出席番号**を入力（次回から記憶されます）
   2. 「📨 きろくを おくる」を押す
   3. 受理された分は、まなびクエストの経験値（EXP）になります

## セキュリティ・プライバシー

- 受信エンドポイントは「学習ログ送信キー」が一致する POST だけを受け付けます。
  キーが未設定の間は受信を停止します
- レコードはサーバー側で study.v1 仕様 §9 の受け入れ条件（スキーマ・UUID・appId・数値範囲・サイズ）で
  検証され、満たさないものは破棄されます。同一 ID の再送は重複として無視されます
- 学習開始時刻は、既定で「日付＋時間帯（午前/午後/夕方以降）」に丸めて保存されます（仕様 §4.1）。
  「初期設定」の `学習ログ時刻精度` を `分` にすると HH:mm まで記録されます
- 送信キーはページの設定として端末に保存されます。合言葉はクラス運用のいたずら防止が目的であり、
  機密情報を守るためのものではありません。EXP 付与量は「初期設定」の
  `学習アプリ経験値係数` / `学習アプリ経験値上限` で調整（0 で無効化）できます
