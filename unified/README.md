# 🎒 まなびクエスト（統合版）

小学校の学習活動を **記録 → 可視化 → ゲーミフィケーション** する Google Apps Script 製 Web アプリです。
これまで別々に運用していた 3 つのプロジェクトを、**1 つのスプレッドシート・1 つの Web アプリ**に統合しました。

| 旧プロジェクト | 主な機能 | 統合後 |
|---|---|---|
| Manabi_Quest（学びクエスト） | 経験値・レベル・ガチャ・アバター・ミッション・バッジ | 「ホーム」「クエスト」「ひろば」タブ |
| assignment portfolio（学習の足あと） | タイピング・100マス計算・読書・成長・自主学習の記録 | 「きろく」タブ |
| performance portfolio（授業の記録） | 授業/テストのふり返り・道徳ノート・AI所見・PDF | 「きろく」タブ＋教員用画面＋シートメニュー |

## 統合で変わったこと（設計のポイント)

1. **データベースは 1 つ**
   すべてのシート（名簿・記録・ゲームデータ・所見）を 1 つのスプレッドシートに集約。`setupDatabase()` がワンクリックで全シートを自動生成します。
2. **バッチ処理・済フラグの廃止 → 保存時に即時経験値付与**
   旧版は「別シートの記録を定期バッチで走査して経験値化」していましたが、統合版は記録がアプリ内保存になったため、**保存した瞬間に経験値・ミッション進捗へ反映**されます。トリガー設定や外部シート ID の管理は不要です。
3. **記録は保護者向け資料・所見に活用**
   - 学期末に全児童分の **学習ポートフォリオPDF**（記録＋ふり返り＋ゲーム実績）を自動生成
   - ふり返り記述から **AI が所見材料を抽出** → 全体所見・道徳所見を AI 生成（Gemini / 任意機能）
4. **AI所見材料の自動ストック（旧「授業の記録」の週案照合を強化して内蔵）**
   - 教員が「指導事項」シート（アプリの「AI所見」タブから登録可）に単元名・ねらいを登録しておくと、児童が授業/テストのふり返りを**保存した瞬間**に AI が記述を分析
   - 指導事項と照合したうえで、学習指導要領の**3観点タグ・おすすめ度つき**のエピソードとして「所見材料」シートへ自動ストック（めあての達成・挙手回数・目標点との差などの定量データも分析に使用）
   - 保存時に処理できなかった分は「所見抽出」フラグが空のまま残り、教員画面のボタンまたはシートメニューの一括抽出があとから回収
   - ストックした材料から、教員画面のワンクリックで**全体所見のドラフトを AI 生成**（「全体所見」シートにも保存）

## セットアップ手順

### 1. スプレッドシートとスクリプトの準備

1. 新しい Google スプレッドシートを作成する
2. 「拡張機能 → Apps Script」を開き、このフォルダの各ファイルを作成する
   - `.gs` ファイル → そのままの名前でスクリプトファイルとして追加（**01→08 の順に作成**）
   - `index.html` / `css.html` / `js_core.html` / `js_student.html` / `js_teacher.html` → HTML ファイルとして追加
   - `appsscript.json` → プロジェクト設定で「マニフェストを表示」を ON にして内容を置き換え
3. スプレッドシートに戻って再読み込みし、メニュー **「🎒 まなびクエスト管理」→「① 初期セットアップ」** を実行
   → 全シートがヘッダー・初期設定・サンプルミッション/バッジつきで生成されます

### 2. 名簿の登録

「児童マスタ」シートに入力します。

| 出席番号 | 名前 | ニックネーム | メールアドレス | 累計経験値 | 経験値 | 交換ポイント | 最終ログイン日 |
|---|---|---|---|---|---|---|---|
| 1 | 山田太郎 | たろう | taro@example.jp | 0 | 0 | 0 | |
| `担任` | 佐藤先生 | さとう | sato@example.jp | | | | |

- **出席番号に「担任」と入れたアカウントが教員用画面**になります
- 児童マスタにないアカウントはアプリを利用できません（登録案内が表示されます）

### 3. Webアプリとして公開

「デプロイ → 新しいデプロイ → ウェブアプリ」

- 実行ユーザー: **自分（デプロイするユーザー）**
- アクセスできるユーザー: **組織内の全員**（学校ドメイン）

発行された URL を児童に配付（Classroom 等に掲載）します。

### 4. 任意設定

| 機能 | 設定方法 |
|---|---|
| アバター画像 | ドライブのフォルダに `0001.png` 形式で画像を置き、「初期設定」にフォルダ ID を記入 → メニュー「② アイテム画像のIDを自動登録」。アイテムは「アイテムマスタ」に登録（カテゴリはアバター構成シートの列名と対応） |
| AI 所見機能 | Apps Script の「プロジェクトの設定 → スクリプト プロパティ」に `GEMINI_API_KEY` を追加 |
| AI所見材料の自動抽出 | 「初期設定」の `AI所見材料の自動抽出` が `ON`（既定）だと、ふり返り保存時に自動でAI分析（`OFF` にすると一括抽出のみ）。「AI所見」タブで指導事項（単元・ねらい）を登録すると照合精度が上がります |
| 道徳AIフィードバック | 「初期設定」の `道徳AIフィードバック` を `ON` に（保存時に自動生成。Classroom コース ID を設定すると個別配信も可能） |
| 経験値のバランス | すべて「初期設定」シートで調整可能（係数・固定値・ガチャ排出率など） |

## 画面構成

### 児童用
- **ホーム** — レベル・経験値バー・アバター・ミッション・お知らせ・最近のできごと・バッジ
- **きろく** — 8 種類の記録入力（タイピング/100マス/読書/成長/自主学習/授業/テスト/道徳）と履歴・グラフ・目標管理
- **クエスト** — ガチャ（1回/10連）・アイテム交換・アバター着せ替え・プロフィール
- **ひろば** — みんなのアバター・各種ランキング（経験値/今日のMVP/タイピング/100マス）

### 教員用
- **ダッシュボード** — クラス統計（今週の記録件数・活動児童数）・児童一覧
- **児童の詳細** — 個人の全記録・ふり返り・活動ログを一覧（面談・所見の材料に）
- **AI所見スタジオ** — 指導事項（単元・ねらい）の登録 / 未処理ふり返りの一括AI抽出 / 児童別の所見材料ストック閲覧・削除（3観点タグ・おすすめ度つき）/ 全体所見ドラフトのAI生成・コピー
- **管理・出力** — ポイント配布 / お知らせ管理 / **学期末ポートフォリオPDF** / 所見材料メモ

### スプレッドシートメニュー（教員）
- 初期セットアップ / アイテム画像 ID 登録
- AI 所見材料の抽出（未処理の授業・テストのふり返り → 所見材料シート）
- 全体所見・道徳所見の AI 生成（「生成」列にチェック → メニュー実行）

## ミッション・バッジの条件キー

ミッションマスタ・バッジマスタの行を追加するだけで拡張できます。

**ミッション条件キー**: `RECORD_TYPING` `RECORD_CALC` `RECORD_READING` `RECORD_GROWTH` `RECORD_STUDY` `RECORD_LESSON` `RECORD_TEST` `RECORD_MORAL` `PLAY_GACHA` `TOTAL_EXP_WEEK` `TOTAL_STUDY_WEEK` `TOTAL_READING_WEEK` `TOTAL_CALC_WEEK`
（種別: デイリー / ウィークリー / 協力）

**バッジ条件キー**: `CURRENT_LEVEL` `TYPING_SPEED_MAX` `TYPING_COUNT` `CALC_COUNT` `CALC_PERFECT_COUNT` `READING_COUNT` `STUDY_COUNT` `GROWTH_COUNT` `LESSON_COUNT` `TEST_COUNT` `MORAL_COUNT` `LOGIN_STREAK_DAYS` `PROFILE_UPDATED` `PROFILE_COMPLETE` `GACHA_COUNT` `INVENTORY_COUNT` `MISSION_REWARD_COUNT`

## 旧版からのデータ移行

1. 統合版のセットアップ完了後、旧スプレッドシートの各記録シートの**データ行**を統合版の同名シートへコピー
   （列構成はほぼ同じです。統合版の「道徳ノート」は学年列を持たない点にだけ注意）
2. 旧・学びクエストの「児童マスタ」「インベントリ」「アバター構成」「獲得バッジ」「プロフィール」「ログ」も同様にコピー
3. 旧版の Google フォーム経由の提出を使っていた場合は、統合版ではアプリ内フォームに移行するため不要になります

## 統合版のアップデート（既存利用者向け）

スクリプトファイルを差し替えたあと、メニュー **「① 初期セットアップ」を再実行**してください。
「指導事項」シート・不足しているヘッダー（ふり返りシートの「所見抽出」列、所見材料シートの拡張列など）・新しい設定項目（`AI所見材料の自動抽出` など）が、既存データを壊さずに追加されます。

## 技術メモ

- ランタイム: GAS V8 / タイムゾーン: Asia/Tokyo
- フロント: Bootstrap 5 + SweetAlert2 + Google Charts（SPA構成、`js_core` / `js_student` / `js_teacher` に分割）
- 書き込み系 API はすべて `withLock_()`（LockService）で排他制御
- 設定は `CacheService` で 5 分キャッシュ（変更後はメニューの「設定キャッシュをクリア」）
- メールアドレス比較はすべて小文字化・trim 済みで統一
